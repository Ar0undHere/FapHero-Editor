# FapHero Editor

ブラウザ上で完結する譜面・メディア・Funscript 統合エディタです。単一の HTML ファイル（`FHeditor.html`）で構成されており、外部ビルドなしで動作します。

## 主な機能

* **譜面タイムライン**
  * シングルノーツ・ロングノーツ・イベント・BPM 変化・拍子変化の配置、選択、移動、ロングノーツの伸縮、削除に対応。
  * 複数選択・範囲選択、カット / コピー / ペースト、アンドゥ / リドゥ（最大200件）に対応。
  * BPM や拍子変化を考慮したグリッド描画・スナップおよび時刻／拍変換に対応。
* **アイテムタイムライン＆プレビュー**
  * 動画・画像・音声メディアの読み込み（ドラッグ＆ドロップ、読み込みボタン、シングルノーツツールでのクリック）と行（レイヤー）管理、トリミング、波形表示に対応。
  * 座標・拡大率・回転・透明度・基準点・音量・エフェクト（ぼかし、色調整、ドロップシャドウ、振動、トリミング、モザイク、RGBずらし、グロー、カラーオーバーレイ、ビネット、フィルムノイズ、走査線など）とキーフレームイージングに対応。
  * グループ化による複数メディアへの一括パラメータ／エフェクト適用に対応。
  * 16:9 キャンバスでのリアルタイムプレビュー、レーン角度／中央ドット位置／ノーツ形状・色／ヒットエフェクト／イベントテキストのカスタマイズに対応。
* **Funscript 生成＆モーショントラッキング**
  * ノーツからの自動キーフレーム生成（平時上下の選択、往復時間、上下端位置、速度制限、イージング／数式 `f(u)` による区間補間）と手動編集・デバイス動作プレビューに対応。
  * 動画内の指定領域をテンプレートマッチング（SAD）で追跡し、縦／横の動きを Funscript キーフレームへ変換するモーショントラッキング機能を搭載。
* **プロジェクト保存＆書き出し**
  * 使用中メディアを同梱した `.fhp`（ZIP 形式、`project.json` + `media/`）の保存・読み込みに対応。
  * WebM（VP9/Opus）、MP4（H.264/AAC・WebCodecs／Mediabunny 利用時）、`.funscript` のエクスポートに対応（480p / 720p / 1080p、24 / 30 / 60 fps）。
* **テーマ＆UI カスタマイズ**
  * ダーク / ライト / システム準拠テーマの切り替えと、パネル分割バーのドラッグによるレイアウト調整に対応。

## 使い方

1. `FHeditor.html` をモダンな Web ブラウザで開きます。
2. 必要に応じて「情報と設定」タブの「サンプル譜面を読み込む」からデモ譜面を読み込むか、メディアファイルをタイムラインへドロップします。
3. ツールバーでツール（カーソル、シングル、ロング、イベント、BPM、拍子）やグリッド分割数を選択して編集し、必要に応じて `.fhp` で保存または動画／`.funscript` をエクスポートします。

> **注意**: 動画・音声の書き出しは実時間再生を伴うため、完了までブラウザタブを表示したままにしてください。また、JSZip や MP4 変換用ライブラリ（Mediabunny）の読み込みにはネットワーク接続が必要です。

## 主なショートカット・操作

| 操作 | ショートカット / マウス操作 |
| :--- | :--- |
| 再生 / 一時停止 | `Space` |
| 先頭へ移動 | `Home` |
| 1グリッド（または1フレーム）移動 | `←` / `→` |
| ツール切り替え | `1`（カーソル）〜 `6`（拍子） |
| グリッド分割数の直接入力 | グリッド選択を `Ctrl` / `Cmd` + クリック |
| 再生速度の変更 | `[` / `]` |
| ズームの変更 | `-` / `+`（`=`）、または `Ctrl` + ホイール |
| タイムラインスクロール | ホイール（アイテムタイムラインの縦スクロールは `Shift` + ホイール） |
| スナップの一時無効化 | ドラッグ／配置中に `Alt` キー押下 |
| 選択アイテムの削除 | `Delete` / `Backspace` |
| カット / コピー / ペースト | `Ctrl` / `Cmd` + `X` / `C` / `V`（貼り付けはクリックで確定、`Esc` で解除） |
| アンドゥ / リドゥ | `Ctrl` / `Cmd` + `Z` / `Ctrl` + `Shift` + `Z`（または `Ctrl` + `Y`） |
| プロジェクト保存 | `Ctrl` / `Cmd` + `S` |

## 技術スタック・外部依存

* **HTML5 / CSS3 / Vanilla JavaScript**（Canvas 2D API、Web Audio API、MediaRecorder API、WebCodecs API）
* **JSZip**（`.fhp` アーカイブの作成・展開）
* **Mediabunny**（MP4 変換利用時に動的読み込み）
